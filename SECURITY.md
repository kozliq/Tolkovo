# Безопасность Tolkovo

## Что программа делает с твоими данными

- **Голос и текст не покидают Mac.** Распознавание идёт локально, на модели GigaAM.
- **В интернет Tolkovo ходит один раз** — чтобы скачать модель с Hugging Face (или с зеркала, если Hugging Face недоступен). Файл сверяется по SHA-256 с хешем, зашитым в программу; если не совпал — удаляется.
- **Никакой аналитики, телеметрии и автообновлений.** Отправка текста в облачные нейросети, которая была в Handy, выключена.
- **Продиктованный текст не пишется в логи.**
- **Окна программы ограничены:** строгая политика безопасности (CSP), без доступа к файлам и к сети, только нужные права.

## Как проверить сборку

Каждый DMG собирается на GitHub Actions из открытого кода. Рядом с ним в релизе лежит SHA-256 и подтверждение происхождения сборки:

```
shasum -a 256 ~/Downloads/Tolkovo-*.dmg
gh attestation verify ~/Downloads/Tolkovo-*.dmg -R kozliq/Tolkovo
```

## Нашёл уязвимость?

Не публикуй её в открытых issues. Напиши через [приватный отчёт GitHub](https://github.com/kozliq/Tolkovo/security/advisories/new) — отвечу и исправлю как можно быстрее.

Поддерживается только последняя версия.
