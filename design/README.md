# Дизайн-референсы Tolkovo

Эти файлы — макеты экранов, нарисованные вместе с автором. Это HTML с инлайн-стилями:
открой в браузере или читай как спецификацию. Цвета, размеры, отступы, тексты — брать отсюда.
Разметку `<x-dc>`, `{{...}}` и `DCLogic` не копировать — это формат редактора макетов, не наш код.

| Файл | Что это |
|---|---|
| `Main.dc.html` | Первый запуск, шаг 1: привет + два разрешения |
| `Download.dc.html` | Шаг 2: загрузка модели — пилюля наливается бордовым как прогресс |
| `Ready.dc.html` | Шаг 3: «Готово. Говори.» + клавиши ⌥ + Space |
| `Live.dc.html` | Запись: полная бордовая пилюля + стеклянный пузырь с живым текстом |
| `States.dc.html` | Три состояния пилюли и анимация цикла налилась → ушла вниз |
| `Settings.dc.html` | Настройки: хоткей, пилюля всегда/при записи, автозапуск, словарь |
| `Dmg.dc.html` | Окно установщика DMG |

## Токены

- Бордовый (жидкость, акценты): градиент `#A3263C` → `#5B1426`, плоский акцент `#8E2138`, точка/курсор `#C23A52`
- Стекло окна: `rgba(24,24,29,0.64)` + blur 40px, обводка `rgba(255,255,255,0.12)`, радиус 26px
- Стекло пилюли: `rgba(255,255,255,0.10)` + blur 24px, обводка `rgba(255,255,255,0.30)`
- Текст: основной `rgba(255,255,255,0.95)`, второстепенный `rgba(255,255,255,0.64)`. Бордовым текст НЕ пишем — только белым.
- Шрифт: системный SF Pro (в макетах Onest как замена).
- Кнопка: белая капсула, тёмный текст, высота 44px.
