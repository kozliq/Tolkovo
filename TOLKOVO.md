# Tolkovo — продуктовый план

Источник правды о том, что мы строим. Читать перед ЛЮБОЙ задачей.
Дизайн — в папке `design/` (макеты экранов + токены в `design/README.md`).

## Что это

Tolkovo — бесплатная, офлайн, приватная голосовая печать для macOS для русскоязычных людей.
Нажал хоткей — сказал — текст появился там, где курсор. Автор — kozliq.

Технически это форк [Handy](https://github.com/cjpais/Handy) (MIT, CJ Pais).
**От Handy берём только мотор:** запись, распознавание, вставку текста, хоткеи.
**Лицо Handy не используем:** его экраны, настройки, списки моделей и языков заменяются нашими.

Позиционирование: «Говори с нейросетями голосом — бесплатно и по-русски».

## Принципы (не нарушать)

1. **Бесплатно навсегда.** Никаких подписок, триалов, платных функций, ключей.
2. **Приватно.** Звук и текст не покидают компьютер. Никакой телеметрии, аналитики, облачных
   API — даже opt-in. Единственное сетевое обращение — одна загрузка модели.
3. **Тихо.** Никаких напоминаний о донатах. Донат — только пункт в меню строки меню.
4. **Ноль выбора.** Один язык — русский. Одна модель — GigaAM v3 E2E-RNN-T, качается сама.
   Пользователь не видит названий моделей, мегабайт, языков. Всё техническое — за ссылкой
   «Дополнительно» в настройках.
5. **Минимализм.** Пользователь видит только пилюлю. Окно — при первом запуске и по желанию.
6. **Лёгкий апстрим.** Внутренние имена Handy в Rust (`handy_app_lib`, крейты, модули)
   не переименовываем. Новый код — в отдельных файлах, в существующих — минимальные вставки.

## Правила публичности (честная игра)

- Программа и репозиторий ничего не собирают о людях: нет форм, аналитики, cookies, сторонних
  шрифтов и счётчиков. Нечего обрабатывать — нечего нарушать.
- Нигде в программе, README и материалах не упоминаем VPN и способы обхода блокировок.
- Не ссылаемся из программы и README на соцсети, запрещённые в РФ.
- Донаты — только добровольные, ничего не открывают и не ускоряют. Никаких «купи/оплати».
- Интерфейс программы — полностью на русском. Латиница — только имена собственные (Tolkovo, GitHub).

## Дизайн

**Цвет.** Интерфейс монохромный: стекло, белый, графит. Единственный цвет — **бордовый**
(в тон Burgundy у iPhone 18 Pro): жидкость в пилюле, отметки, переключатели. Никакого синего,
никакого розового. Текст бордовым не пишем.

**Пилюля** — вертикальная стеклянная капсула (~64×140), белый микрофон **внизу по центру**.
Никаких бликов-полосок на стекле. Жидкость внутри — как вода в игрушке-кораблике.
- Покой: пустое прозрачное стекло.
- Запись: по нажатию плавно наливается насыщенным бордовым снизу (~0.5 с) почти доверху —
  поверхность видна, мягко покачивается и волнуется сильнее, когда человек говорит.
- После отпускания: жидкость плавно уходит вниз, текст вставляется.
- Появляется и исчезает не рывком: стекло растекается в размытую кляксу и тает,
  появляется обратно с пружинкой.
- Всегда поверх окон, на всех рабочих столах и в полноэкранных приложениях, не забирает фокус.
- Перетаскивается в любое место, позиция запоминается. Клик = старт/стоп записи.
- По умолчанию всегда на экране; в настройках — «Всегда» / «При записи».
- Уважает «Уменьшить движение» и «Уменьшить прозрачность».

**Живой текст** (v0.2): во время записи слева от пилюли стеклянный пузырь, в котором появляются
слова (перераспознавание буфера ~каждые 0.5 с). Уточняемые слова полупрозрачные. В поле ввода
вставляется только финальный текст.

**Первый запуск** — три экрана: привет + разрешения → загрузка (пилюля наливается как прогресс,
без названий моделей и мегабайт) → «Готово. Говори.» Дальше окно закрывается навсегда.

**Настройки** — одно окно: хоткей, пилюля всегда/при записи, автозапуск, словарь.
Ссылка «Дополнительно» — модели и всё техническое.

**Без Dock:** живёт в строке меню. Меню: Настройки · Поддержать проект · Выйти. Автозапуск.

**Стекло:** `tauri-plugin-liquid-glass` (NSGlassEffectView на macOS 26+, фолбэк на 14–25).
